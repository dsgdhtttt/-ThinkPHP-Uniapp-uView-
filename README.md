# 【全开源】活动报名表单系统（ThinkPHP+Uniapp+uView）

源码地址：ym7k.com/18968/

这套基于 ThinkPHP+Uniapp+uView 开发的活动报名表单系统为全开源版本，无加密限制，专注解决各类线上活动收集报名信息的需求，兼顾移动端体验与后台管理能力，支持自主部署和二次定制，适合企业活动、社团招募、讲座预约、赛事报名、问卷统计等多种场景使用。

系统核心是灵活的表单自定义功能，也是区别于简易表单工具的关键。管理员无需编写代码，在后台可视化搭建表单内容，可自由添加多种表单组件，包括单行文本、多行备注、单选、多选、下拉选择、图片上传、日期时间选择、手机号、身份证等字段。每个字段都可以单独设置是否必填、输入提示文字、字段排序、是否隐藏，还能设置选项联动逻辑，根据上一题的选择，展示或隐藏后续字段，适配复杂的报名收集场景。表单可以创建多套独立模板，不同活动使用不同表单，互不干扰，方便长期运营多场次活动。

前端依托 Uniapp 搭配 uView 组件库，适配多端访问。用户可以通过 H5 链接、小程序入口进入报名页面，页面布局简洁，加载速度稳定，表单填写交互友好，上传图片支持预览，填写过程中自动保存草稿，避免误退出导致信息丢失。报名页面支持自定义标题、活动简介、封面图、报名须知、活动时间地点，还能设置报名截止时间、活动名额上限，名额满后自动关闭报名通道，无需人工值守操作。同时支持开启报名验证，比如短信验证码校验，有效过滤恶意重复提交、垃圾报名数据。

订单与报名记录管理模块，实现报名数据一站式管控。所有用户提交的报名信息实时汇总到后台，管理员可以按活动分类查看报名列表，支持按姓名、手机号、提交时间等条件检索筛选，快速定位指定报名记录。后台支持查看报名详情、修改备注、审核报名状态，可设置待审核、审核通过、审核驳回等状态，驳回时可以填写原因同步通知用户。系统自带数据导出功能，支持一键导出 Excel 表格，导出后可直接用于线下签到、人员整理、信息存档，省去手动整理数据的麻烦。

签到核销功能适配线下落地场景。后台可以为每一条报名记录生成核销码，支持工作人员在移动端后台扫码核验，核验成功标记已签到，防止一人多次入场、代报名冒领的情况。同时可以实时统计签到率，区分已签到、未签到人员，方便现场活动有序开展。

配套的通知与基础配置功能完善。管理员可以开启消息提醒，用户提交报名、审核状态变更时，通过短信或者站内消息通知报名人，让参与者及时知晓结果。后台支持自定义站点名称、logo、底部说明、客服联系方式，也可以自由配置权限，创建多个子管理员账号，分配不同权限，比如只允许查看数据、负责签到核销，做到多人协同管理。

因为整套源码全开源无加密，具备很强的拓展可塑性。有开发能力的使用者，可以基于现有框架新增功能，比如增加报名费在线支付、报名表单分页、更多样式主题、对接第三方通知接口等，不受加密文件束缚。系统架构成熟稳定，部署简单，数据全部自主留存，不用依赖第三方 SaaS 表单平台，不用担心数据泄露、平台关停、收费涨价等问题。

总的来说，这套活动报名表单系统把表单搭建、报名收集、审核管理、签到核销、数据导出融为一体，兼顾普通运营人员的易用性和开发者的二次开发需求，轻量化但功能闭环，是自主搭建活动报名渠道不错的选择。
